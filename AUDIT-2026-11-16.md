# Audit 2026-11-16, implemented as 1.6.3

Baseline audited: `main.lua` 4706 lines, 163 top-level locals, 274 `tl` fields,
41 config keys, 4 offline suites, no git, no linter config, no `perf_log.txt`
(so no measured p95), `perf` off by default. Method: four read-only subagents
(architecture, performance, quality, standards) plus line-level verification of every
P0 and of the P1/P2 items listed below. Two subagent conclusions were corrected during
that check and are recorded here rather than acted on: the orphan timeline slot loses
only the first hit of an unregistered ability (later hits land in the created table), and
the 195 `os.clock` calls mostly sit behind 0.1 s/2 s gates, so they are not per-frame cost.

## Deferred, with reasons

- `LEARN` wiring (P1-1): changes which paths run; needs a controlled single-boss comparison.
- `GetNearestValidReceivedFrame(..., {})` out-table reuse (P1-2): whether the engine accumulates into the table is unverified.
- `queueTimeline` predicate extraction (P2-6): only the ordering bug was fixed; splitting a 102-line decision function is a reviewed step of its own.
- Module extraction of guard/shachi/movement (P2-9): the seams are in place (`ad_policy`, `ad_input`, `ad_query`, `ad_timeline`); moving decision code is not a mechanical edit.
- No in-game measurement yet: `perf` still defaults off, so there is still no p95 from a real session. The log format now makes one line sufficient when it is turned on.

## Lessons recorded

- The LuaJIT/Lua 5.4 local budget counts **every** `local` in the chunk, including those
  inside `do` blocks: two edits failed with `main function has more than 200 local variables`
  until an equal number of locals was released.
- An array literal followed by `.join(...)` inside a PTC program can fail to parse; a single
  string built with explicit newlines is safer for these one-shot scripts.
- `selene` 0.31 has no built-in `lua54`; a custom std with `base: lua51` plus UE4SS globals
  works, and the two Lua-5.4-only calls (`collectgarbage("generational")`, two-argument
  `math.atan`) carry `-- selene: allow(incorrect_standard_library_use)` with the reason.
- `selene` exits non-zero on warnings alone: gates must read its verdict line, not its code.
